Semi-Supervised Learning for Speech Recognition

  • Period: Group project, KTH (Speech Recognition)
  • Tech Stack: Python, PyTorch, scikit-learn, NumPy, SciPy, soundfile, Jupyter Notebook
  • Project: drive.google.com/drive/folders/1nqFCQDbm8tvqswLtrKYsSjISshjjQd_y

Ran model training experiments using a pseudo-labeling approach: trained an initial supervised model, generated soft labels on unlabeled audio, then iteratively fine-tuned on the expanded dataset.

Benchmarked semi-supervised performance against fully supervised baselines across multiple label ratios using test accuracy, Phoneme Error Rate (PER) and edit distance; responsible for experimental design, training runs and the written report.
