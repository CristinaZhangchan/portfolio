RAG Question-Answering Pipeline

  • Period: March 2026 - April 2026
  • Tech Stack: Python, RAG, sentence-transformers, ChromaDB, Google Gemini 2.0 Flash, Jupyter, uv
  • Github: github.com/CristinaZhangchan/RAG-mechanism-

Implemented a full Retrieval-Augmented Generation (RAG) pipeline from scratch: document ingestion, chunking, local vector embedding with sentence-transformers, semantic retrieval via ChromaDB, and LLM-synthesised answer generation with Gemini 2.0 Flash.

Designed the retrieval layer to ground LLM responses in source documents, demonstrating how RAG mitigates hallucination, a core challenge in production LLM systems.

Managed the development environment with uv and secured API credentials via .env, following production-aware engineering practices.
